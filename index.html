Installing it safely

Alerty isn't code-signed yet, so your OS will show a one-time warning on first launch. This is normal for independent apps — here's exactly what to click.

1

Open the downloaded .dmg and drag Alerty into your Applications folder.

2

Double-clicking will say "Alerty is damaged and can't be opened." This is a standard macOS warning for independent apps that aren't Apple-notarized — it is not actually damaged. Don't move it to Trash.

3

Open System Settings → Privacy & Security, scroll down — you'll see "Alerty was blocked." Click Open Anyway, then confirm once more. You only need to do this the first time.

Still stuck? Open Terminal and run: xattr -cr /Applications/Alerty.app — then open it normally. This removes the browser's download quarantine flag, which is what triggers the warning.
1

Run the downloaded .exe installer.

2

Windows SmartScreen will show "Windows protected your PC." This appears because the app is new, not because anything is wrong.

3

Click "More info", then click the "Run anyway" button that appears.

This warning may reappear on future updates too — that's expected for unsigned apps and is safe to click through each time.

Verify the download (optional)

If you want to confirm the file wasn't tampered with in transit, compare its SHA-512 hash against the value electron-builder published with this release.
